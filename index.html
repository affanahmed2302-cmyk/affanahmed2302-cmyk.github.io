01LIVECASE STUDY

Hatch — BMS Campus Network

One place for students to find teammates, clubs, and ship projects together.

ProblemCampus collab was scattered across chats and groups.
OutcomeLive Next.js + Supabase product on Vercel.
Next.jsTypeScriptSupabaseVercel
Open live → GitHub

Constraints

Fast iteration, real campus users, auth + structured data.

Decisions

Next.js App Router. Supabase auth + Postgres. TypeScript end-to-end.

Architecture

Client → Supabase Auth → Postgres → Vercel

Next

Teammate matching, club workflows, activation metrics.

02LIVECASE STUDY

Aether — Distributed KV Store

Fault-tolerant key-value store with Raft consensus and a live cluster simulator.

ProblemNeeded real systems depth — not another CRUD app.
OutcomeGo + Raft + Docker · interactive demo on this site.
GoRaftDockerChaos
Open simulator → GitHub

Constraints

Majority commit, leader election, survival when a node dies.

Decisions

Raft as the product. Go for concurrency. Docker for multi-node runs.

Architecture

Client → Leader → Followers (AppendEntries)

Next

Benchmarks, snapshotting, observability.

03LIVECASE STUDY

GestureOS — Touchless Control

Control a machine with hand gestures via webcam. MediaPipe tracking — works on phone.

ProblemHands-free control without extra hardware.
OutcomePython + MediaPipe + OpenCV · live camera demo.
PythonMediaPipeOpenCVCV
Open camera demo → GitHub

Constraints

Consumer webcam, real-time latency, varied lighting.

Decisions

MediaPipe landmarks → gesture rules → actions.

Architecture

Webcam → OpenCV → MediaPipe → Actions

Next

Multi-gesture sequences, left-hand support.
