01LIVECASE STUDY

Hatch — BMS Campus Network

One place for students to find teammates, clubs, and ship projects together.

ProblemCampus collab was scattered across chats and groups.
OutcomeLive Next.js + Supabase product on Vercel.
Next.jsTypeScriptSupabaseVercel
Open live → GitHub

Constraints

Fast iteration, real campus users, auth + structured data without heavy backend ops.

Decisions

Next.js App Router for UX speed. Supabase for auth + Postgres. TypeScript end-to-end.

Architecture

Client (Next.js)
   → Supabase Auth
   → Postgres (teams, clubs, projects)
   → Vercel edge deploy

Next

Deeper teammate matching, tighter club workflows, measure activation.

02LIVECASE STUDY

Aether — Distributed KV Store

Fault-tolerant key-value store with Raft consensus, chaos testing, and a live cluster simulator.

ProblemNeeded real systems depth — not another CRUD app.
OutcomeGo + Raft + Docker · interactive demo on this site.
GoRaftDockerChaos
Open simulator → GitHub

Constraints

Majority commit, leader election, survival when a node dies.

Decisions

Raft as the product. Go for concurrency. Docker for reproducible multi-node runs.

Architecture

Client → Leader (log · WAL · KV)

03LIVECASE STUDY

GestureOS — Touchless Control

Control a machine with hand gestures via webcam. Real MediaPipe tracking — works on phone too.

ProblemHands-free control without extra hardware.
OutcomePython + MediaPipe + OpenCV · live camera demo.
PythonMediaPipeOpenCVCV
Open camera demo → GitHub

Constraints

Consumer webcam only, real-time latency, stable under varied lighting.

Decisions

MediaPipe landmarks → gesture rules → system actions. Web demo for proof.

Architecture

Webcam → OpenCV frames
      → MediaPipe hands
      → Gesture classifier
      → Actions (mouse / media)

Next

Multi-gesture sequences, better left-hand support, FPS targets.
